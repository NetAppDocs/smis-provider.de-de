= Probleme mit der Laufzeitbibliothek
:allow-uri-read: 
:icons: font
:imagesdir: ./media/
:pp: &#43;&#43;


[role="lead"]
NetApp SMI-S Provider kann unter Windows auf Laufzeitbibliotheksprobleme stoßen. Das erforderliche Microsoft Visual C{pp} Redistributable Package behebt diese Probleme.

* *Ausgabe*
+
Es treten Probleme mit der Laufzeitbibliothek auf.

* *Korrekturmaßnahmen*
+
Installieren Sie das Microsoft Visual C{pp} 2010 Redistributable Package (x86) von www.microsoft.com.
